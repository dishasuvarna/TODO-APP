# Todo App

A simple Todo List application built using Node.js, Express.js, HTML, CSS, and JavaScript.

## Features

* Add tasks
* Edit tasks
* Delete tasks
* Mark tasks as completed
* Search tasks

## Installation

```bash
npm install
npm start
```

Open:

```text
http://localhost:3000
```

## Technologies Used

* Node.js
* Express.js
* HTML
* CSS
* JavaScript
